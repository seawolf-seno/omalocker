# Locker: guide for AI agents

This folder is one person's school life as Markdown notes. The format is in
OmaLocker's `docs/format.md`. The person works in Obsidian; you work in these files.

## Rules

- Never change the person's own words. Add, suggest, or write inside an
  `<!-- omalocker:... -->` block you own.
- Ask before deleting, moving or renaming notes; renames break links.
- Keep frontmatter valid YAML with a `type`.
- Never open notes with `private: true` or anything in `People/` that describes
  a real student. Never write a student's name anywhere outside this Locker.
- Words, not scores. No points, streaks or failure language.
- Until the school's AI policy allows more, help only with the person's own
  plans, ideas and writing, not records about other people.
